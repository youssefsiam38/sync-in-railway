# Security

- Sign-up is closed: the only account created by the template is the administrator from `INIT_ADMIN_LOGIN`. Other accounts are created by the administrator in the app.
- Secrets (`INIT_ADMIN_PASSWORD`, `MARIADB_ROOT_PASSWORD`, `SYNCIN_AUTH_*`) are generated by Railway and never written to the repository, logs, or image layers. The admin password is printed nowhere by the template; it is visible only in the service variables.
- The MariaDB port is not published. The app reaches it over Railway's private network.
- Auth: the upstream login is rate-limited (6 requests per 60 s on `/api/auth/login`), and access/refresh tokens are signed with separate secrets.
- Report vulnerabilities in Sync-in to the upstream project's security advisory channel (https://github.com/Sync-in/server/security). Report template issues in this repository's issues.
